What is AngouriMath?

A symbolic algebra library for .NET: it works with formulas as formulas, the way SymPy does in Python. It parses x^2 + 1 = 0 from a string, solves it to { i, -i } exactly, and differentiates, integrates, simplifies, takes limits and works with sets, matrices and boolean logic.

It is a library, not an application or a web service: you install it from NuGet and call it from C#, F# or a Jupyter notebook, with no server, no account and no limit on use. It is MIT-licensed, so that includes commercial projects. To see it before installing anything, try it live: the library itself, running in your browser.

How the answers are checked

A computer algebra system is full of answers that look right. So the library's answers are checked against independent arithmetic, on inputs nobody chose, not only against a list of expected strings:

  • Integrals are differentiated back and compared with the integrand. Of a sample of 402 of Rubi's integration problems, two from every file in all nine of its families, all 402 are answered and check out (on bfc7f5bdc, November 2026).
  • Roots are put back into their equations, and random equations are solved and cross-checked against an independent numerical search, so a missing root is found as well as a wrong one.
  • Computations from Modenov's Problems in Geometry, 642 of them, run on every change, with the book's own errata as rows the library must not confirm: 480 are solved, and none is wrong.
  • Every answer that changes between versions is listed, with the old value and the new one, in BREAKING-CHANGES.md.

Where the library cannot settle a question, it says so: an unsolved equation comes back as written, not as a guess.

Where it is used

  • Calculators and modelling. A formula a user types is parsed and compiled to a fast function, which can be evaluated millions of times to draw a plot or run a model.
  • LaTeX. The input syntax is close to how mathematics is written ({ x : x > 0 } is a set in set-builder notation), and Latexize() prints any expression as LaTeX for a renderer.
  • Education and quiz apps. Solve, simplify or check a student's answer, with a cancellation token to stop a request that runs too long.
  • Agents. The library's MCP server lets a language model hand its algebra to a system that checks it.
