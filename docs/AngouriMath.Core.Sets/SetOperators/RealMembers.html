RealMembers​(AngouriMath.​Entity.​Set.​IndexedUnionf,​AngouriMath.​Entity.​Set)

 Method (no overloads)

Summary

The members of a family of roots family that are in a set of reals
real -- the reals or an interval with numbers for its ends -- as a
finite set; null where the family is not of the shape read here or a
membership is not decided, and the intersection stays as written.

Remarks

Each member is read as c + k n in the index n, with numbers c and
k, k not 0. Its imaginary part is Im(c) + n Im(k). Where k is not
real that is 0 at one n only, n0 = -Im(c) / Im(k), so the family has one real
member where n0 is a whole number in the index set and none otherwise: every
exponential's family over the complex numbers, ln(2) + 2 pi i n, is real at
n = 0 alone, which makes e ^ x = 2 and x in RR the root ln(2). Where
k is real every member is real if Im(c) = 0 and none is otherwise, and the
members inside a bounded interval are the n between its ends mapped back, at most
MostRealMembers of them: sin(x) = 1/2 on [0; 2 pi] is
{ pi/6, 5 pi/6 }. Over an unbounded set there are infinitely many, and the
intersection stays.
n0 is a ratio of the imaginary parts as evaluated, taken as whole within
1e-30; the member at it is then put in real as an exact
expression, which is what decides it.
https://github.com/asc-community/AngouriMath/issues/2319
 A member with a condition, as an equation with a denominator has, is read by its
expression, and the index is put into the whole member: 2 pi n provided not 2 pi n = 0 has no member at n = 0, so sin(x)/x = 0 on [-10; 10] is
{ -3 pi, -2 pi, -pi, pi, 2 pi, 3 pi }. A condition not decided at an index leaves
the intersection as written. https://github.com/asc-community/AngouriMath/issues/2502
