SolveWithParameters​(AngouriMath.​Entity.​Variable[])

 Method (no overloads)

Summary

Solves the system as Solve(AngouriMath.Entity.Variable[]) does, and says what each parameter
in the answer is and which set it ranges over.

Parameter "vars"

The unknowns, as Solve(AngouriMath.Entity.Variable[]) takes them.

Returns

The rows Solve(AngouriMath.Entity.Variable[]) answers, in
Rows, and in
Parameters each symbol of theirs that is neither an
unknown nor a symbol of the equations, in the order it first appears, with the set it
ranges over: t_1 over CC for an unknown nothing constrains (RR where Codomain is Real), n_1 over ZZ for a whole number of periods or a branch of the Lambert W function,
r_1 over RR for the argument of a number of given modulus, and the
t_1 of floor(x) = 1 over [0, 1). The list is empty where the
answer has no parameter. null where Solve(AngouriMath.Entity.Variable[]) is, and where a parameter is one this cannot name the set of.

Remarks

Each row is a family of solutions, one for each value of the parameters it mentions,
taken from their sets; a row need not mention all of them. A name stands for one set
throughout the answer, and within a row two parameters are two names: in
sin(x) = 1/2, sin(y) = 1/2 the rows read
(pi/6 + 2 pi n_1, pi/6 + 2 pi n_2). Rows are separate families, so a
name in two rows is chosen independently in each.
 A row may say where it holds, as 1 + t_1 provided t_1 in RR and t_1 >= 0 and
t_1 < 1 does; the set of its parameter is said here either way.
 https://github.com/asc-community/AngouriMath/issues/212

Exception "NotSufficientlySupportedException"

As Solve(AngouriMath.Entity.Variable[]).

Example

var solved = MathS.Equations("sin(x) - 1/2").SolveWithParameters("x", "y");
Console.WriteLine(solved!.Rows);
foreach (var (parameter, domain) in solved.Parameters)
    Console.WriteLine($"{parameter} in {domain}");

Prints
[[pi / 6 + 2 * pi * n_1, t_1], [pi - pi / 6 + 2 * pi * n_1, t_1]]
n_1 in ZZ
t_1 in CC
