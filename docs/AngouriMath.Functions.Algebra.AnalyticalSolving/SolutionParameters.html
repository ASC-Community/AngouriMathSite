SolutionParameters

← Back to list of classes

Description

Summary

The parameters a solve brings into its answer -- n_1 for a whole number of periods,
t_1 for an unknown nothing constrains, r_1 for an argument -- each minted here
with the set it ranges over, so that the set is said where the parameter is made and not
read back from its name.
#212

Remarks

While a system is being solved a scope is open, and within it one name stands for one
set: a name already minted for another set is passed over for the next free one, so a
t from floor(x) = 1, which ranges over [0, 1), and the t of
an unknown left free are never both t_1 in one answer.
 Outside a scope, as in the solve of one equation, minting is
CreateUnique(AngouriMath.Entity,System.String) and nothing more. A scope is a thread-static pointer
read once per parameter minted; the solve it covers is synchronous.
