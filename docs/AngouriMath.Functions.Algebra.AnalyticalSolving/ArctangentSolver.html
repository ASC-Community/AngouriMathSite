ArctangentSolver

← Back to list of classes

Description

Summary

An equation linear in arctangents of polynomials or quotients of polynomials,
m_1 arctan(a_1) + ... + m_n arctan(a_n) = c with integer m_j and at least two
arctangents, solved by taking the tangent of both sides.

Remarks

Write A for the sum of the arctangents. Since cos(arctan a) = 1 / sqrt(1 + a^2) is never zero, e^(i A) divided by the product of the cosines is the product of the
1 + i a_j, each to its m_j; as polynomials, P + i Q. Then
Q cos c - P sin c is sin(A - c) divided by that product, which holds for complex
a_j as well, so the polynomial equation Q cos c = P sin c has every root of the
original and no root is lost. It also has the roots of A = c + k pi for every other
integer k, so each candidate is put back into the equation as written, under the
principal arctangent, and kept only where it holds. arctan(x) + arctan(2x) = pi/4 is
3x = 1 - 2x^2, whose roots are (-3 +- sqrt(17)) / 4; at the negative one the
sum is -3 pi / 4, so the answer is { (sqrt(17) - 3) / 4 }. Newton's method
answered these in decimals, and arctan(x) - arctan(2x) = 1, whose roots are complex,
not at all.
