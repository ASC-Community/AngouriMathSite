FactorialSolver

← Back to list of classes

Description

Summary

c (x + k)! + P(x) = 0, with c a rational that is not zero, k a whole
number and P a polynomial over Q: its whole roots, exactly, and the rest of
its roots left as the equation. gamma(x + k) is (x + k - 1)!, so this is the
gamma function's equation as well. https://github.com/asc-community/AngouriMath/issues/2538

Remarks

Where P is not 0 there are infinitely many roots, so no finite set is the answer.
The factorial has a pole at each negative whole number and tends to the same infinity on
both sides of the interval between two of them, while the least of its size there tends
to 0; on every other such interval far enough out, its sign is the sign of
-P / c there, so the equation changes sign twice in it. x + x! = x^3 has
two real roots in each of (-4, -3), (-6, -5), (-8, -7) and so on, and Newton's method,
started inside [-10, 10]^2, answered 13 decimals without -3.0200.
 The whole roots are found by trying each whole number from the first at which the
factorial is defined, exactly, and the search ends with a proof that no larger one is a
root. For n >= 1, |P(n)| <= S n^d, where d is the degree and
S the sum of the sizes of the coefficients. For n >= d,
((n + 1) / n)^d <= (1 + 1/d)^d < 3, so once (n + k)! >= 2 as well,
a step multiplies the factorial by n + k + 1 >= 3 and the bound by less. The
first n past both at which |c| (n + k)! > S n^d is therefore the last
one there is any need to try.
