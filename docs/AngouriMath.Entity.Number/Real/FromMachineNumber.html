FromMachineNumber

 Method with 2 overloads

  • FromMachineNumber​(PeterO.​Numbers.​EDecimal,​System.​Double)

    Summary

    FromMachineNumber(PeterO.Numbers.EDecimal) of value, whose exact value is the
    Doublemachine -- a Double, or a Single widened to one, which is exact; NaN where there is no such double. A value that
    is provably no small rational, which is almost every double, is a Real without
    the downcasting's search; every other value goes through it as before.

    Remarks

    The search reads the decimal's mantissa, more than half of the bytes and the time a double took to
    become a number; the double already has the value exactly, as a ratio of two machine integers.

  • FromMachineNumber​(PeterO.​Numbers.​EDecimal)

    Summary

    A number from a Single, a Double or a Decimal, which carries
    that type's digits and not the working precision's: it is the small rational it is near within
    PrecisionErrorZeroRange, ten to the minus sixteen, so that 1m/3 is 1/3. https://github.com/asc-community/AngouriMath/issues/1944
