SolveSystem​(AngouriMath.​Entity,​AngouriMath.​Entity.​Variable[])

 Method (no overloads)

Summary

Solves a system of equations written as one statement, a conjunction of equations,
jointly for several variables, as Equations(AngouriMath.Entity[]) solves one written
as a list.

Parameter "system"

Equations joined by and, nested or not: x + y = 3 and x - y = 1. An
equation a = b is read as a - b = 0, and a chain a = b = c is the
conjunction a = b and b = c. One equation is a system of one, and an expression
that is not a statement is read as equal to zero, as SolveEquation(AngouriMath.Entity,AngouriMath.Entity.Variable) reads one.

Parameter "variables"

The unknowns, in the order of the answer's columns, as many as there are equations or
not, as Solve(AngouriMath.Entity.Variable[]) takes them.

Returns

What Solve(AngouriMath.Entity.Variable[]) answers for the equations: a matrix
with a row for each solution and a column for each variable, a variable the system
leaves free becoming a parameter. null where no solution was found,
which includes a system that has none, as x + y = 1 and x + y = 2, and one the
solver could not settle. Also null where a conjunct is not an
equation -- an inequality, an in, an or, a not or a boolean --
since solving the others alone would answer a different question; solve such a
statement for one variable at a time with Solve(AngouriMath.Entity.Variable).

Remarks

Solve(AngouriMath.Entity.Variable) on the same statement solves it for one variable,
with the others as parameters: x + y = 3 and x - y = 1 for x is
{ 3 - y } ∩ { 1 + y }, the values of x for each y. This is the
question for all of them at once, and answers the point (2, 1).
https://github.com/asc-community/AngouriMath/issues/2450

Exception "NotSufficientlySupportedException"

As Solve(AngouriMath.Entity.Variable[]): the work the call may spend ran out
before the system was solved, which is "not settled", not "no solution".

Example

var solutions = MathS.SolveSystem("x^2 + y^2 = 25 and x - y = 1", "x", "y");
Console.WriteLine(solutions);

Prints
[[-3, -4], [4, 3]]
