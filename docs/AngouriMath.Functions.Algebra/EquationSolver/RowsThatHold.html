RowsThatHold​(System.​Collections.​Generic.​List{AngouriMath.​Entity},​AngouriMath.​Entity.​Variable[],​System.​Collections.​Generic.​List{System.​Collections.​Generic.​List{AngouriMath.​Entity}})

 Method (no overloads)

Summary

The rows of rows that satisfy each of equations,
or null where a row is shown not to for some value of the symbols
left in it.

Remarks

A row is dropped on the evidence a root of one equation is dropped on,
IsEvidenceAgainstUnlessEnclosed(AngouriMath.Entity): an equation that, with the row put
in, has no symbol left and is a number away from zero, or is no finite number at all, as
x ln(y) is at (0, 0). Such a row is no solution for any value of anything,
so dropping it loses none.
 A row with symbols left in it is tried at one value of them, and one that fails there
declines the system instead of being dropped. It may hold for other values, as
sqrt(t^2) = t does for every positive t, and the rows left would read as
all of the solutions. A symbol of the system's own is tried at a positive value that
is not whole, and a parameter that a row brings with it, a t_1 or an
n_1, at a whole one, since an n_1 stands for those only.
 Anything else is kept, as a root of one equation is: a residual that cannot be
evaluated, or one too small next to its terms to be told from rounding.
 Except where the row is exact and an interval enclosing a residual leaves out zero,
which declines the system. An exact row is a solution only where every residual is
exactly zero, so such a row is none, however small the residual is next to its terms;
and that the tolerance took it for one means rounding reached the elimination, which
can have lost true rows as well as made this one. In
y^2 - 2, x^2 + (P - Q y) x - 3, with (1 + sqrt(2))^70 = P + Q sqrt(2),
P - Q sqrt(2) is 1.6e-27, and the zero tolerance of one equation's solve
reads it, and terms of that size, as nothing: the row [-2P, -sqrt(2)] leaves
-2 against terms of 4e53, under a tolerance relative to them, and all
four solutions were gone. Rounding reaches an exact elimination through downcasting,
which v3 removes; the decline is to be reconsidered then, and the check kept.
