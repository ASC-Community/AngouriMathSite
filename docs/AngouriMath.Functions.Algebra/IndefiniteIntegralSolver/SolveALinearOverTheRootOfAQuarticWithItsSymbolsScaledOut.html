SolveALinearOverTheRootOfAQuarticWithItsSymbolsScaledOut​(AngouriMath.​Entity,​AngouriMath.​Entity.​Variable,​System.​Boolean)

 Method (no overloads)

Summary

A linear over the square root of a quartic whose symbols are a scale of the variable,
(alpha x + beta)/sqrt(P(x)) with P(s t) = C M(t), M monic with rational
coefficients and C a positive square: under x = s t it is a constant times
(t + nu)/sqrt(M(t)) for a rational nu, which the logarithmic ansatz answers
where it is elementary. Rubi's 1.3.2
x/sqrt(-44375 b^4 + 576000 b^3 c x + 576000 b^2 c^2 x^2 + 5308416 c^4 x^4), which is
ln(p + q sqrt(P))/(18432 c^2) for p of degree eight.

Remarks

The ansatz reads rational coefficients, and the scaling of the variable takes one symbol
and reads what is left by simplifying, which does not take C out from under the
root, so the row was declined with b = c = 1 answered. Here s is the
symbols of the ratio of two adjacent coefficients, each coefficient of M is
checked to be a number, and sqrt(C) is written as the monomial it is, its powers
multiples of four. The question in t has no symbols, so it is not scaled again.
