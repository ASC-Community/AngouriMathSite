TheQuotientDisagreesAboutTheVertex​(AngouriMath.​Entity,​AngouriMath.​Entity,​AngouriMath.​Entity,​AngouriMath.​Entity.​Variable)

 Method (no overloads)

Summary

Whether expr over derivative takes two real values
at two points where candidate, a quadratic written as a sum, takes
one -- about its vertex, every other symbol pinned -- which no function of the candidate
does. False for any other candidate, where the evaluations are not worth it (see
IsWorthEvaluatingAtRealPoints(AngouriMath.Entity,System.Boolean)), and wherever a real value cannot be had.

Remarks

TheQuotientDisagreesWhereTheCandidateRepeats(AngouriMath.Entity,AngouriMath.Entity,AngouriMath.Entity,AngouriMath.Entity.Variable) for a quadratic: p x^2 + q x + r takes one value at x and -q/p - x. Under A + B t + C t^2 the quotient of
sqrt(c + d t) (a + b t)^3 (A + B t + C t^2)/(1 + t^2) by B + 2 C t, what the
tangent makes of Rubi's 4.3.4.2, was simplified for a second to be refused. Real values
only: what is tried after the simplification keeps the value on the real line, and a root
of a negative number off it may take the other branch.
