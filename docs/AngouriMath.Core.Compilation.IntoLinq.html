  • TensorCompilation

    Summary

    How a matrix and the arithmetic on it compile: a Matrix node becomes
    a GenTensor`2 over its elements' common type, filled element by
    element from the compiled elements, and a sum, difference, product, quotient or power
    with a matrix in it becomes the tensor operation of the same name -- PiecewiseAdd,
    MatrixMultiply, PiecewiseMultiply by a scalar, MatrixPower -- so
    that the compiled delegate runs GenericTensor's arithmetic rather than a tree of scalar
    operations.

    Remarks

    The methods the compiled tree calls are the public generic ones below, closed over each
    element type at compile time in the kit for that type and named through expression
    trees, the way CompilationProtocol keeps its own tables: no generic type or
    method is constructed at run time, which a trimmed or NativeAOT build could not do.
    https://github.com/asc-community/AngouriMath/issues/363
    https://github.com/asc-community/AngouriMath/issues/526

  • ThreeValuedLogic

    Summary

    The compiled statements, with a third truth value for one that has none: i > 1 compares numbers that are not ordered, and NaN > 1 compares with no number at all.
    Each is null, as EvalNumerical leaves either as NaN, and the
    connectives follow Kleene's tables, as EvalNumerical's do: (i > 1) or true is
    true, (i > 1) and false is false, and not (i > 1) has no value.
    https://github.com/asc-community/AngouriMath/issues/2195
